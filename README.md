# Catalyst Character Builder

Standalone offline-first character creation, sheet, rules-pack, and advancement module for future integration with Catalyst.

Architecture documentation is being established before application code. See `docs/architecture/` and `AGENTS.md`.

**Official visual system:** [Obsidian & Frost Blue — Architecture 011](docs/architecture/011-CATALYST-DESIGN-SYSTEM.md). Global accent: `#6EA9CF`; gold is optional for genre-specific sheet skins only.
